# Plok

Tidy files, instantly. A Windows desktop app for organizing folders, FL Studio libraries and Downloads, finding duplicates and cleaning up drive space.

**Download:** [Plok.exe](https://github.com/gavintsc/plok/raw/main/Plok.exe)

Plok updates itself. Windows may show "Windows protected your PC" the first time: click **More info**, then **Run anyway**.
